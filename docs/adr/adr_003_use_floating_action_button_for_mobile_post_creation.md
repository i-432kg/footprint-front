# ADR: モバイルの新規投稿導線に Floating Action Button を採用する

## ステータス
Proposed

## 背景
`footprint-front` では PC 画面を前提に、タイムラインや検索画面の右サイドバーに `SideUserActions` を配置し、新規投稿モーダルを開く導線を提供している。

モバイル対応では `TwoColumnLayout` により 1 カラム化し、サイドバーはメインコンテンツ下へ再配置する方針とした。
この場合、既存の新規投稿ボタンは画面下部までスクロールしないと見つけにくくなり、フィード閲覧中の主要アクションとしてはアクセス性が低下する。

そのため、モバイル時の新規投稿導線をどこに配置するかを決定する必要がある。

## 問題
- モバイルでは右サイドバーが存在しないため、PC と同じ位置に投稿導線を置けない
- サイドバーをメイン下に移動するだけでは、投稿ボタンがファーストビューから外れやすい
- ヘッダーには検索、マイページ、メニューがあり、投稿ボタンを追加すると `375px` 幅で窮屈になりやすい
- 投稿は主要アクションであり、モバイルでも常時アクセスしやすい導線が必要である

## 決定
モバイルの新規投稿導線には、画面右下に表示する Floating Action Button を採用する。

PC では従来どおり、右サイドバー内の `SideUserActions` カードから新規投稿モーダルを開く。
モバイルでは `SideUserActions` の投稿モーダル制御を活かしつつ、右下の Floating Action Button から同じ投稿モーダルを開く。

## 設計方針

### 1. モバイル時のみ Floating Action Button を表示する
Floating Action Button は `useMobileLayout()` によるモバイル判定で表示を切り替える。

PC では表示しない。
PC の投稿導線は既存の右サイドバーに維持する。

### 2. ヘッダーには投稿ボタンを追加しない
ヘッダーにはすでに以下の導線がある。

- 検索
- MyPage
- モバイルメニュー

`375px` 幅ではこれ以上アイコンを増やすと視認性と押しやすさが落ちるため、投稿導線はヘッダー外に配置する。

### 3. Safe Area を考慮して右下に固定表示する
iPhone などの下部 UI と干渉しにくいよう、配置には `env(safe-area-inset-bottom)` を考慮する。

想定する配置:

- `position: fixed`
- `right: 20px`
- `bottom: calc(24px + env(safe-area-inset-bottom))`
- 他のモーダル表示中は必要に応じて非表示または背面化する

### 4. 投稿モーダルの実装は既存の `SideUserActions` を活用する
新規投稿モーダルの状態管理、バリデーション、送信処理は既存の `SideUserActions` に集約されている。

そのため、まずは `SideUserActions` 内でモバイル時に Floating Action Button を表示し、既存の `openModal()` を呼び出す。

将来的に投稿導線を複数画面で共通化する必要が出た場合は、投稿モーダルを専用コンポーネントへ切り出す。

## 選択肢

### 案1: ヘッダーの検索アイコン隣に投稿ボタンを配置する
不採用。

理由:

- `375px` 幅でヘッダーが窮屈になる
- 検索、MyPage、メニューと投稿が並び、主要導線の優先順位が分かりづらくなる
- ヘッダーの情報密度が上がり、誤タップのリスクが増える

### 案2: 右下に Floating Action Button を配置する
採用。

理由:

- フィード画面における投稿導線として一般的で認知しやすい
- ヘッダーを圧迫しない
- スクロール位置に関係なく投稿アクションへアクセスできる
- 既存の投稿モーダル制御を活かして実装できる

### 案3: フッターメニューを用意し、その中に投稿導線を配置する
不採用。

理由:

- アプリ全体のモバイルナビゲーション設計が必要になり、変更範囲が大きい
- 今回の目的である投稿モーダルのモバイル対応に対して過剰である
- `Home / Search / Map / Post / MyPage` などの情報設計を別途決める必要がある

### 案4: タイムライン本文上部に投稿ボタンを配置する
不採用。

理由:

- 実装は軽いが、スクロールすると導線が見えなくなる
- 投稿アクションの常時アクセス性が低い
- サイドバー導線が下に移動する問題を十分に解決できない

## 実装手順
1. `SideUserActions.vue` に `useMobileLayout()` を導入する
2. PC では既存のプロフィールカードと投稿ボタンを維持する
3. モバイルでは右下 Floating Action Button を表示する
4. Floating Action Button から既存の `openModal()` を呼び出す
5. 投稿モーダルをモバイル時 `fullscreen` または準全画面表示に調整する
6. `375px`、`390px`、`768px` で表示と操作を確認する

## 期待する効果
- モバイルでも投稿アクションへ常時アクセスしやすくなる
- ヘッダーの情報密度を増やさずに主要導線を追加できる
- 既存の投稿モーダル処理を活用でき、変更範囲を抑えられる
- 将来的なフッターメニュー導入時にも、投稿導線の移行判断がしやすくなる
